Liicivo_02 🎄🍓
一个以冰蓝色圣诞树、粉色发光草莓和冬日氛围为主题的 3D 手势交互网页。
✨ 项目特
- 冰蓝色发光圣诞树粒子
- 粉色光晕草莓与动态飘落效果
- 白色雪花持续飘落
- 自定义照片展示
- 摄像头手势交互
- 圣诞主题音乐播放器
